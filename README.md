# 📊 Project Management Details & Budget Analytics Dashboard

## 📌 Project Overview

This project is an interactive **Project Management Analytics Dashboard** built using Power BI. 
The goal of this dashboard is to provide project managers, executives, and financial controllers with clear insights into:
* Overall project portfolio health and delivery status
* Budget allocation vs. actual expenditure tracking
* Resource and project manager workload distribution
* Project categorization across priorities, types, and geographic locations

It allows decision-makers to track budget utilization efficiency, identify project bottlenecks, and optimize resource allocation.

---

## 📌 Main Features & Visuals

### 🔸 KPI Summary Cards (Portfolio Health)
* **Total Projects:** `83` active, planned, or completed projects tracked across the organization.
* **Total Expense:** `$545.5K` spent across all project lifecycles.
* **Total Budget:** `$856.2K` total allocated financial resources.
* **Budget Utilization:** `64%` overall budget consumption rate, indicating controlled spending within baseline limits.

### 🔸 Financial & Status Performance Analysis
* **Budget and Expense by Quarter_Year:** Area & Line chart tracking budget allocation vs. actual spending from Q1 2022 to Q4 2022, highlighting spend peaks (e.g., Q3 2021).
* **Project Status Breakdown:** Column chart categorizing projects by operational stage (**In Progress: 39**, **Completed: 19**, **Planned: 13**, **On Hold: 7**, **Cancelled: 5**).
* **Priority Distribution:** Donut chart showing project portfolio split by urgency level (**Medium: 22.89%**, **Very Low: 22.89%**, **Low: 21.69%**, **Very High: 18.07%**, **High: 14.46%**).

### 🔸 Workload & Regional Breakdown
* **Project Type Distribution:** Horizontal bar chart displaying volume across categories like Facilities (38), Security Services (16), Performance Management (12), Network Services (9), Client Service (5), and Research Support (3).
* **Workload by Project Manager:** Column chart analyzing project assignment distribution per manager, identifying key leaders (e.g., James Potter managing 46 projects, Sophia Quinn managing 19).
* **Geographic Distribution:** US Map chart illustrating project presence across different states.

---

## 🧠 Key Business Questions Answered

This dashboard answers the following strategic project management questions:
1. What is our overall budget utilization rate, and are projects staying within financial thresholds?
2. How many projects are currently active, on hold, or cancelled?
3. Which quarter experienced the highest expenditure compared to allocated budgets?
4. Which project managers carry the highest project load, and is redistribution required?
5. What are the dominant project types and geographic locations for current operations?

---

## 💡 Business Value

This dashboard supports:
* **Cost & Budget Control:** Preventing cost overruns by continuously tracking actual expenses against quarterly budgets.
* **Risk & Bottleneck Mitigation:** Early identification of projects put **On Hold** or **Cancelled** to take corrective actions.
* **Resource Load Balancing:** Optimizing workload distribution among Project Managers to avoid burnout and delay.
* **Strategic Portfolio Alignment:** Ensuring project priorities match strategic organizational goals.

---

## 🎨 Visuals Used

* **Card Visuals with Sparklines:** KPI metric display for total projects, financial summaries, and percentage metrics.
* **Area & Line Combo Chart:** Time-series budget vs. expense comparison.
* **Clustered Column Charts:** Distribution analysis for project status and project manager workloads.
* **Horizontal Bar Chart:** Category-based breakdown for project types.
* **Donut Chart:** Proportionate percentage distribution for project priority levels.
* **Filled Map (Choropleth Map):** Spatial/geographic mapping of project locations across regions.
